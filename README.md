# 🌌 AI Universe – All AI Tools in One Place

**One Platform. Endless AI Possibilities.**

AI Universe is an all-in-one website that brings different AI tools together in one place. Users can easily explore AI chatbots, text-to-image generators, and creative AI platforms by clicking on their respective logos.

## 🚀 Features

- 🤖 **AI Chat & Chatbots:** Explore popular AI tools like ChatGPT, Claude, Gemini, Perplexity, Grok, and more.
- 🎨 **Text-to-Image AI Tools:** Discover Midjourney, DALL·E, Adobe Firefly, Leonardo AI, Ideogram, and other image-generation platforms.
- 🔗 **Direct Website Links:** Visit AI tools by clicking their logos.
- 🎬 **Animated Introductions:** Includes videos showcasing AI tools.
- 💻 **Simple Interface:** Easy-to-use and beginner-friendly design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Images (PNG)
- MP4 Animations

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Navigate to the `Front-End` folder.
4. Open `index.html` in your browser.
5. Explore the available AI tools.

## 🎯 Project Goal

To make discovering and accessing different AI tools easier by bringing them together on a single platform.
